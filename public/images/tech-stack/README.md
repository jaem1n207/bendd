# Tech Stack logos

These assets are served locally for the home page. Technology names are curated
in `src/components/home/consts/tech-stack.ts`; no repository names or usage records
are included in that data.

The SVG geometry comes from the following collections in `@iconify/json` 2.2.418:

- [SVG Logos](https://github.com/gilbarbara/logos): CC0-1.0.
- [Simple Icons](https://github.com/simple-icons/simple-icons/tree/16.2.0): CC0-1.0.
  Single-color marks use the brand colors from that version's `data/simple-icons.json`.
- [Devicon](https://github.com/devicons/devicon): MIT; see `LICENSE-Devicon.txt`.

The Grok mark comes from
[`@lobehub/icons-static-svg` 1.95.1](https://unpkg.com/@lobehub/icons-static-svg@1.95.1/icons/grok.svg):
MIT; see `LICENSE-LobeIcons.txt`. The Obsidian mark uses `logos:obsidian-icon`
from the SVG Logos collection above.

Two assets come directly from the projects' public websites:

- [ArkType favicon](https://arktype.io/image/favicon.svg).
- [Emotion logo](https://emotion.sh/logo-96x96.png).

Collection SVG color literals are expressed in equivalent HSL notation. Logo
geometry is unchanged. Monochrome appearance and the color reveal are CSS layers,
with no remote icon requests or added icon-library runtime.

Brand names and marks belong to their respective owners.
