# Craft 커서 안내

사용자 확인: 2026-10-03. 기준: `main`의 `f483b4a`.

- 목적: 방문당 몇 번 탐색하는 작품의 조작 방법을 현재 요소에서 알려준다.
- 범위: 홈의 Dock, 단계별 코드 설명, 문자별 텍스트 셔플과 Dock 데모 설정.
- 표현: 기본 커서와 흑백의 둥근 안내 배지. 라이트·다크 테마를 따른다.
- 커서: 클릭 버튼은 `pointer`, 비활성 버튼은 `default`,
  Dock 구분선은 `ns-resize`, 설정 슬라이더는 `ew-resize`, 선택 가능한 코드는 `text`.
  커스텀 화살표를 그리거나 기본 커서를 숨기지 않는다.
- 위치: 배지는 기본 커서의 오른쪽 아래에 놓는다.
  화면 가장자리에서는 배지만 안쪽으로 옮긴다.
- 진입: 투명도 0 → 1, 배지 크기 0.95 → 1, 150ms.
- 퇴장: 배지의 반대 변화, 100ms. 기본 커서는 항상 표시한다.
- 곡선: `cubic-bezier(0.19, 1, 0.22, 1)`. 반동 없음.
- 전환: 위치와 문구는 즉시 바뀐다. 동일한 배지를 유지한다.
  CSS transition은 진행 중인 값에서 이어진다.
- Dock 드래그: 작품 밖에서도 놓을 때까지 `크기 조절 중`을 유지한다.
  설정 슬라이더도 조절 중인 항목의 안내를 유지한다.
  드래그 중에는 조절 방향의 기본 커서를 유지하고,
  종료·취소·포커스 이탈·언마운트 때 복구한다.
- 동작 줄이기: 확대·축소를 제거하고 투명도만 50ms로 전환한다.
- 터치·키보드: 따라다니는 배지를 표시하지 않고 기존 안내와 조작을 유지한다.
- 구현: 기존 `motion/react`의 MotionValue로 위치를 갱신하고,
  transform과 opacity만 전환한다. 의존성을 추가하지 않는다.

| 영역               | 안내                                     |
| ------------------ | ---------------------------------------- |
| Dock 아이콘        | 클릭해 선택                              |
| Dock 구분선        | 위아래로 끌어 크기 조절 · 우클릭해 설정  |
| Dock 드래그        | 크기 조절 중                             |
| Dock 설정          | 조작할 항목의 이름과 드래그 안내         |
| 코드 본문          | 스크롤해 설명 읽기                       |
| 코드 버튼          | 이전 설명 / 다음 설명 / 해당 단계로 이동 |
| 비활성 코드 버튼   | 첫 설명입니다 / 마지막 설명입니다        |
| 셔플 문자          | 클릭해 다시 섞기                         |
| 동작 줄이기의 셔플 | 동작 줄이기 사용 중                      |

검증 초점: 기본 커서의 모양, Dock 툴팁과 안내의 겹침, pointer capture와 취소 시 커서 복구,
설정 포털의 소유권, 화면 가장자리, 테마·동작 줄이기·터치·키보드.
