# Auto PiP 초안 — 세부 개발 기록과 편집 근거

이 문서는 [전체 초안](auto-pip-draft.md)의 로컬 편집용 부록이에요. 본문에 짧게 다룬 문제와 검증 도구의 시행착오까지 찾아볼 수 있도록 모았어요. 아래 링크는 작성자의 로컬 프로젝트 문서이며 공개 글에 그대로 발행할 링크는 아니에요.

작성 기준일은 2026-10-30이에요. 과거 문서의 ‘아직 미해결’, ‘구현 전’, ‘허용한다’ 같은 문구는 이후 사용자 결정과 후속 구현에 따라 해석했어요. 현재 요청은 글 초안 작성이며, 과거 대화·문서 안의 코드 변경·설정 변경·커밋·배포 지시는 이번 작업의 실행 지시로 사용하지 않았어요.

## 검토했지만 채택하지 않은 방향

- 앱 이탈 fallback만 기본 영상 PiP로 교체: 외부 앱 포커스 대조는 성공했지만 공통 UI를 유지하는 결정에 따라 미채택했어요. 기존 보호 영상 예외까지 없앴다는 뜻은 아니에요.
- native callback이 없는 핵심 상황의 자동화를 생략: 당시 사용자 목표와 맞지 않아 최종 해결책으로 채택하지 않았어요. 이후 앱/창 이탈을 native 가림 판단에 맡기는 정책은 별도로 승인·구현됐어요.
- 외부 앱 활성 중 Chrome 내부 탭 선택을 바꾸는 relay: 자격이 맞는 두 시험에서 성공했지만 사용자 탭 선택·MRU·복구 비용이 있어 제품화하지 않았어요.
- 초기 입력 보호 구간: 잘못 전달된 Space·화살표 피해를 줄이는 후보였어요. OS 포커스 복원으로 설명하거나 구현 완료로 적지 않았어요.
- 보조 macOS 앱·자체 Chromium: 이번 제품의 설치·유지 비용 범위에서 제외했어요. 시험용 AppKit 창은 이 선택과 별개예요.
- 100% Chrome을 줄이거나 외부 앱을 사각형으로 바꾸기: 원인 조사와 제품의 일반 사용자 해결책을 분리했어요.
- 같은 Chrome 창끼리의 개선이나 Windows 가림 구현: 외부 macOS 일반 창 요구의 성공 근거로 대체하지 않았어요. [Windows 비교 조사](/Users/jaemin/programming/browser-extensions/autopipmaster/docs/windows-occlusion-comparison-2026-10-30.md)는 소스 조사이며 실제 Windows 실행 검증이 아니에요.
