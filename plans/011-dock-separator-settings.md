# 011 — 구분선으로 조절하는 Dock

- 기준: 6961f3a 이후 사용자 교정과 2026-10-02 모션 브리프 승인
- 적용: 실제 탐색 Dock, 홈 Craft Dock 데모
- 상태: 구현 완료, 프로덕션 통합 검증 통과

## 확정한 동작

클릭은 260ms의 단발 반동이다. 기본 크기의 15%를 80ms 동안 올라갔다가 180ms에 복귀한다. 탐색과 버튼 활성화는 반동 완료를 기다리지 않는다. 재입력은 현재 위치에서 이어가며 키보드와 동작 감소 설정에서는 장식 이동을 생략한다.

Hover는 기본 크기 × 확대 배율로 계산하고 거리별로 이웃을 확대한다. 기본 크기 32–64px, 기본값 40px이며 확대는 1–2배, 기본값 1.6배다. 1배는 확대 없음이다. 임계감쇠 스프링은 프레임마다 transform만 갱신하며 정지하면 rAF를 종료한다. 화면 공간과 가로 스크롤 상태에 맞춰 시각적 확대를 제한하고 설정값은 보존한다.

두 기존 구분선은 같은 크기와 설정을 공유한다. 위로 2px 끌면 기본 크기가 1px 증가한다. 포인터 캡처와 rAF 병합을 사용하고 놓을 때만 저장한다. Escape, pointercancel, capture 상실, window blur, unmount는 확정하지 않은 값을 복구한다. 터치 탭 또는 키보드 Enter·Space·Shift+F10은 설정을 연다. 구분선 위에 포인터가 올라오면 현재 위치를 고정해 우클릭 타깃이 움직이지 않게 한다.

설정은 누른 구분선 가까이에 고정된 비모달 패널이다. 160ms에 진입하고 100ms에 퇴장한다. 열린 뒤 Dock 크기를 바꿔도 패널과 슬라이더는 움직이지 않는다. 화면 크기가 달라질 때만 경계를 보정한다. 바깥 클릭과 Escape로 닫고, 키보드로 닫으면 실행한 구분선에 포커스를 돌린다.

두 바 슬라이더는 왼쪽이 작고 오른쪽이 크다. 커서 주변 바와 숫자가 반응하며, hover만으로 Dock을 미리 보여준다. 확대 옵션은 중앙 아이콘과 이웃을 확대해 결과를 시연한다. Hover 이탈은 마지막 확정값을 복구하고 클릭·드래그·키보드 입력은 값을 확정한다. 행 오른쪽은 확정값, 툴팁은 현재 미리보기 값을 표시한다.

실제 Dock은 검증된 크기와 배율만 저장한다. 이전 버전의 크기는 유지하고 과거 픽셀 단위 확대값은 새 배율 기본값으로 이관한다. 데모는 별도의 로컬 상태를 사용한다. 드래그용 숫자 DOM은 driver가 소유해 React 텍스트 갱신과 충돌하지 않는다.

## 접근성과 성능

- 구분선 조작 영역: fine pointer 24px, coarse pointer 44px, ns-resize 커서.
- native range는 방향키와 Home/End, label, 현재 값 읽기를 지원한다.
- 동작 감소 설정은 반동·hover 확대·바 파동·숫자 롤링·패널 이동을 생략한다. 명시적 크기 조절과 미리보기는 즉시 반영한다.
- 매 프레임 저장하지 않는다. 구분선 드래그는 DOM driver, 슬라이더는 바뀐 단계에만 상태 갱신한다.
- 새 패키지와 외부 폰트를 추가하지 않는다.

## 검증 기록

초기 회귀 테스트는 별도 Resize 아이콘, 반동 누락, 확대 누락의 세 문제를 재현한 뒤 통과했다. 구분선 hover와 포커스 단계의 이동도 별도 실패 테스트로 재현하고 수정했다. 통합 테스트는 미리보기/확정/취소, 저장 횟수, 두 구분선의 동기화, 실제 Dock과 데모의 독립성, 키보드·동작 감소 설정, SSR와 DOM 소유권을 포함한다.

개발 브라우저에서 40→56px hover 미리보기와 이탈 복원, 드래그 확정 및 새로고침 복원을 확인했다. 미리보기 중 패널 좌표와 Dock의 가로 중심·바닥 위치는 유지됐다. 실제 클릭 직후 안쪽 아이콘의 음수 Y 이동과 이후 복귀를 확인했다. 64px·2배 설정에서 중앙 아이콘은 128px였다. 390×844 화면은 가로 overflow 없이 설정 패널을 화면 안에 유지했다.

최종 단위 검사 51개 파일 / 487개 테스트, 타입·lint·포맷 검사와 프로덕션 빌드를 통과했다. 변경 파일의 lint 경고는 없고 기존 파일의 경고 6건은 유지한다. 홈 폰트는 새 문구에서 결정적으로 다시 생성했으며 103,340바이트다.

프로덕션에서 Home→Craft→Home→Article→Home 이동 시 8개 아이콘의 x/y 변화는 모두 0px였다. 확대 상태에서 구분선 우클릭, 패널 고정 상태의 40→52px hover 미리보기, 클릭 반동도 확인했다. Photos→Music은 tooltip direction=1, 역방향은 -1이며 같은 tooltip ID를 유지했다. 프로덕션 확인 중 새 브라우저 오류는 없었다.

Playwright 회귀 파일은 이번 실행에서 CLI로 돌리지 않았다. 브라우저 확인은 Codex 브라우저로 수행했다. 실제 터치 기기, Safari, 120Hz 성능과 연속 영상 프레임은 미확인이다.
