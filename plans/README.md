# 홈 인터랙션 구현 기록

홈 개편 과정에서 승인하고 구현한 모션 계획이다. 각 문서의 최초 설계와 날짜별 실행 기록을 함께 읽는다.

| 계획                                                                     | 상태      | 범위                                                   |
| ------------------------------------------------------------------------ | --------- | ------------------------------------------------------ |
| [006 — 스크롤 중 초기 등장 순서 유지](006-home-scroll-intent.md)         | 구현 완료 | 스크롤 중 재생 유지, 사용자 조작과 동작 감소 설정 처리 |
| [007 — 처음 보이는 섹션 순차 등장](007-home-viewport-reveal-sequence.md) | 구현 완료 | 화면 진입별 순서, 손글씨 후행, blur 예산               |
| [008 — 코드 전환 속도 조정](008-home-code-walkthrough-timing.md)         | 구현 완료 | 코드 이동과 등장·퇴장, 빠른 입력 처리                  |

최종 홈 모션 정책과 후속 수정은 [홈 모션 명세](../docs/design-docs/home-initial-motion-brief.md)에 기록한다. 008 이후 코드 설명은 좌우 배치와 세부 설명 강조를 지원하며, 설명은 320ms로 전환한다. 코드 행 수에 맞는 프레임 높이는 코드 이동 시작과 함께 650ms의 동일한 가감속 곡선으로 변화한다. 코드 전체가 보이고, 뷰어 내부 스크롤은 부모 페이지로 전파되지 않는다.

이 문서들의 과거 검증 기록은 당시 환경의 관측이다. PR 통합 검증 결과는 PR 본문에 별도로 기록한다. 실제 휴대전화의 촉감과 연속 영상 프레임 검토는 미확인이다.
