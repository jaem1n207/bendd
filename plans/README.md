## 2026-10-02 Dock 수정

사용자가 고른 두 문제에 대해 범위를 제한해 점검했다. framework는 Next.js 15 / React 19, motion/react 12, CSS module, imperative rAF driver이며 실제 Dock은 반복 탐색, Craft Dock은 체험용이다.

8개 범주를 클릭 피드백, hover 확대, 공유 tooltip, 설정/데모 조절에 적용했다. 클릭은 목적/시간/물리성이 문제이며 reduced-motion·sound 경계는 유지한다. 크기 조절은 상호작용 자체가 요구와 다르다. tooltip의 현재 8px/160ms 방향 전환과 위치 유지가 해결되었다는 사용자 확인을 존중한다. 성능은 기존 transform driver와 정지하는 rAF가 장점이지만, 새 드래그에서 매 프레임 React state/저장을 만들지 않도록 계획에 제약을 넣었다. 추가 장식 모션 제안은 없다.

### 실행 및 모션 검토

| Before                           | After                                        | Why                                                 |
| -------------------------------- | -------------------------------------------- | --------------------------------------------------- |
| 클릭 후 20px 상승이 끝난 뒤 하강 | 안쪽 버튼만 3% 눌림, 150ms 진입 / 100ms 복귀 | 탐색 위치와 hitbox를 유지하고 긴 공중 체류를 제거   |
| hover 확대와 설정 슬라이더       | 고정 손잡이를 위아래로 끌어 32–64px 조절     | 요청한 직접 조작으로 통일하고 드래그 종료 때만 저장 |

검토 판정: **승인**. 버튼 눌림은 transform만, tooltip은 기존 위치 이동과 8px/160ms 방향 전환을 유지한다. 직접 크기 조절은 크기 변경 자체가 목적이므로 작은 Dock의 레이아웃 갱신을 허용한다. 포인터 값을 rAF로 병합하고 React state 및 저장은 종료 시 한 번만 갱신한다. Escape·취소·포커스 이탈·unmount는 시작 크기로 복구한다. 키보드와 reduced motion은 장식 이동 없이 동작한다.

새 크기 표시는 빈 DOM slot을 resize driver가 관리한다. React 자식 텍스트와 함께 관리했을 때 발생한 NotFoundError를 재현한 뒤, drag preview·부모 rerender·자식 구조 변경·unmount 회귀를 추가했다.

- 직접 회귀를 RED → GREEN으로 확인했고, 최종 단위 검사 50개 파일 / 473개 테스트를 통과했다.
- 타입·lint·포맷 검사와 최종 프로덕션 빌드를 통과했다. 기존 파일의 lint 경고 6건은 유지한다.
- 프로덕션 브라우저에서 24px 위로 드래그해 40→52px, 모든 아이콘 동시 변경, 중심과 바닥 고정을 확인했다. 실제 크기 reload 복원과 데모 40px 초기화를 확인했다.
- 390×844 화면, 64px 크기에서 페이지 가로 overflow가 없고 고정 손잡이는 44px 너비로 남았다. 손잡이 밖까지 드래그해도 포인터 캡처가 이어지고 페이지 scrollTop은 유지됐다.
- Home↔Craft 및 Home↔Article 이동에서 9개 항목의 x/y 변화는 0px였다.
- 업데이트한 Playwright 회귀 파일은 이번 실행에서 CLI로 돌리지 않았다. 브라우저 조작 검증은 Codex 브라우저에서 수행했다.
- 실제 터치 기기, Safari, 120Hz 성능, 연속 영상 프레임 검토는 미확인이다. Apple 비공개 물리값과의 일치 여부를 주장하지 않는다.

최종 빌드에서도 40→52px 드래그와 badge 표시, reload 복원, 데모 재렌더링을 확인했다. Photos→Music은 direction=1, Music→Photos는 -1이며 tooltip ID와 아이콘 너비가 유지됐다. 최종 프로덕션 확인 중 새 브라우저 오류는 없었다.
