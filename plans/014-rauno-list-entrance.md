# 글 목록 진입 모션 시안

- 대상: `/article`, `/craft`의 공통 `ArticleItem`
- 기준: https://rauno.me/projects (2026-10-02 DOM 시간 표본, 2026-10-03 구분선 CSS 확인)
- 상태: 요약문까지 셔플하는 로컬 시안. 사용 후 요약문 페이드 전환 여부 결정.

## 확정한 방향

**Verdict:** animate
**Trigger:** 직접 진입 또는 다른 섹션에서 목록으로 이동. 상세/시리즈에서 복귀하면 즉시 표시.
**Frequency:** 가끔 방문하는 흐름, 섹션 진입마다 재생.
**Purpose:** 목록 진입의 전환감과 문자 조립 연출. 링크 선택은 완료를 기다리지 않는다.
**Enter:** 행 전체 opacity 0 → 1. 제목·요약·날짜는 함께 셔플하며 원문으로 정착.
**Exit:** 대기 없이 즉시 이동. 별도 퇴장 모션 없음.
**Origin:** 행 위치 이동 없음. 구분선은 왼쪽에서 오른쪽으로 너비 0 → 100%.
**Easing:** 행 linear, 구분선 ease · **Duration:** 행 페이드 300ms, 행 간격 100ms. 선 두 겹은 각각 1초.
**Shuffle:** 30fps, 10회 혼합 구간. 길이에 따라 종료 시점은 달라진다.
**Interrupt:** 언마운트·모션 감소 변경·행 포커스 시 중단하고 원문 복원.
**Reduced motion:** 완성된 텍스트와 행을 즉시 표시. 셔플·페이드 없음.
**Stack:** Motion의 행 단위 tween + 기존 requestAnimationFrame 셔플 + 구분선 가상 요소의 CSS keyframes. CSS가 첫 화면과 JS 실패 시 가독성 보장.

## 긴 목록과 초기 로딩

- 처음 화면에 있는 항목만 순차 지연. 지연은 최대 800ms.
- 스크롤로 뒤늦게 들어온 항목은 순번에 따른 대기 없이 시작.
- 요약문이 숨겨진 모바일 레이아웃에서는 불필요한 요약 셔플 생략.
- JS가 늦거나 실패하면 CSS가 600ms 후 원문 표시. 이미 표시된 원문을 다시 숨기지 않는다.
- 빈 셔플 프레임에도 제목·날짜 높이를 유지하여 행 위치와 관찰 시점이 흔들리지 않게 한다.

## 관찰 근거와 확인할 점

Rauno 행 opacity 표본은 약 300ms의 선형 변화, 이웃 행은 약 100ms 차이를 보였다. 구분선은 가상 요소 두 겹의 width와 background가 변한다. 이 부분은 2026-10-03 원본 CSS에서 확인했다. 문자 셔플은 여러 행에서 동시에 시작했고, 비공백 글자 수 + 약 10 단계를 30fps로 진행하는 패턴과 일치했다. 행 페이드와 셔플 값은 실행 화면의 관찰과 추정이며, 구분선 값은 원본 CSS에서 확인한 값이다.

**Open risk:** 긴 한글 요약문까지 셔플하면 탐색이 산만해질 수 있다. 이번 시안에서 함께 재생한 뒤 요약문만 완성된 문장으로 페이드할지 판단한다. 난수 문자와 폰트·문장 길이가 달라 원본 화면과 픽셀 단위 일치는 보장하지 않는다.

## 구분선 원본 값

- 높이 1px, 왼쪽 고정, 각 1초 ease, fill-mode forwards.
- 아래쪽 선: 투명 → 강조색(50%) → 최종색(100%). 행별 50ms 지연.
- 위쪽 선: 투명 → 강조색(50%) → 투명(100%). 행별 100ms 지연.
- 라이트: 강조 HSL 0 0% 52.3%, 최종 0 0% 90.9%.
- 다크: 강조 HSL 0 0% 49.4%, 최종 0 0% 17.9%.
- 행 페이드 완료와 선 재생 상태를 분리한다. 포커스·모션 감소·상세 복귀 시 최종 너비와 색상으로 표시한다.
- 기존 지연 상한을 공유하고, 화면 밖에서 진입한 항목은 두 선 모두 지연 없이 시작한다.
- 원본의 공개 CSS를 직접 관찰한 값이며, 요약문 길이와 폰트 차이까지 픽셀 단위로 일치한다는 의미는 아니다.
