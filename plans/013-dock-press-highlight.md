# Motion brief — Dock 눌림과 표면 하이라이트

상태: 2026-10-02 사용자 구현 승인 후 구현 및 로컬 검증 완료.

기준 코드: PR #149의 `f591187`. 실제 탐색 Dock과 홈 Craft Dock 데모가 공유하는 아이콘 버튼에 적용한다. 사용자는 점프 대신 눌림과 표면 하이라이트를 선택했다. 과거 009·011의 클릭 반동 수치는 이 설계의 기준으로 사용하지 않는다.

**Verdict:** animate

**Trigger:** 마우스 주 버튼 또는 터치로 아이콘 버튼을 누르면 눌림 상태가 된다. 놓으면 복원한다. 탐색·토글·데모 선택은 기존 click 시점에 실행하며 애니메이션 완료를 기다리지 않는다.

**Frequency:** 기존 브리프에서 정한 방문당 몇 번에서 수십 번. 짧은 직접 조작 피드백으로 제한하고 재생 대기 시간을 만들지 않는다.

**Purpose:** 버튼이 입력에 반응했음을 촉감 있는 눌림과 짧은 표면 명암으로 전달한다. 작업 완료나 성공을 의미하는 표시는 아니다.

**Enter:** 누르는 순간 버튼 안쪽 표시의 scale을 1→0.96으로 바꾼다. 고정된 표면 하이라이트의 opacity를 0→0.12로 바꾼다. 둘 다 0ms이며 누르는 동안 유지한다. 하이라이트는 버튼 안에만 표시하고 아이콘의 형태와 가독성을 유지한다.

**Exit:** 놓으면 scale 0.96→1을 180ms에 복원하고, 하이라이트 opacity 0.12→0은 200ms에 사라진다. 확대 초과나 반복 반동은 없다.

**Origin:** 버튼 중심 50% 50%. 기존 hover 확대에 안쪽 눌림을 합성한다. 바깥 클릭 영역, 이웃 아이콘 배치, 툴팁 기준 위치는 유지한다.

**Easing:** 기존 cubic-bezier(0.22, 1, 0.36, 1) · **Duration:** 누름 0ms, 크기 복원 180ms, 하이라이트 복원 200ms.

**Interrupt:** 복원 중 다시 누르면 그 상태에서 즉시 눌림 목표로 바뀐다. 원래 크기로 리셋한 뒤 재생하거나 애니메이션을 대기열에 쌓지 않는다. 버튼 밖으로 이동해 취소하면 복원하며, pointercancel·창 포커스 이탈·페이지 숨김은 즉시 정리한다. 취소된 입력으로 클릭 기능을 실행하지 않는다. unmount 후 작업을 남기지 않는다.

**Reduced motion:** 크기 변화와 페이드는 생략한다. 포인터 누름의 표면 강조는 즉시 표시·해제한다. 키보드 조작도 장식 이동과 페이드를 생략하며 기존 포커스 표시와 선택·토글 상태를 유지한다. 동작 감소 설정이 아직 확인되지 않았다면 정적으로 처리한다.

**Stack:** 기존 CSS module의 transform·opacity transition과 Dock 입력 방식·동작 감소 분기를 사용한다. 하이라이트는 고정된 레이어의 opacity만 바꾼다. 새 패키지를 추가하지 않는다.

**Open risk:** 밝은 테마에서 12% 하이라이트가 약할 수 있고, 큰 hover 확대에서는 눌림이 더 크게 느껴질 수 있다. 32/40/64px 및 1/2배 확대, 밝고 어두운 테마에서 확인한다. 하이라이트가 아이콘을 흐리게 만들지 않는지 실제 화면으로 판정한다.

## 유지할 동작과 확인할 증거

- 실제 Dock과 데모에 동일한 피드백을 적용한다. 기존 데모 선택점과 설정 복원 버튼의 효과, hover 유지 경계, 소리 설정은 유지한다. 구분선과 슬라이더에는 적용하지 않는다.
- 짧은 클릭, 길게 누름, 빠른 재입력, 누른 채 밖으로 나가기·취소를 확인한다. 버튼 위치와 클릭 영역이 변하지 않고 툴팁과 이웃 아이콘이 흔들리지 않아야 한다.
- 탐색·테마·소리·데모 선택이 애니메이션을 기다리거나 중복 실행되지 않아야 한다. 키보드와 동작 감소에서 기능·포커스·상태 표시가 유지되어야 한다.
- 애니메이션 브리프 승인 뒤 구현한다. 실제 브라우저·터치 기기·연속 프레임 등 검증하지 못한 범위는 구현 결과에서 구분한다.

## 2026-10-02 실행 및 검증

실제 탐색 Dock과 Craft 데모의 공유 `DockSurface`에 포인터 눌림 처리를 연결했다. 버튼 표면과 SVG만 0.96배로 줄이며 native 버튼·링크의 클릭 영역과 데모 선택점은 축소하지 않는다. 기존 hover 확대와 표면 음영은 유지한다.

누름은 0ms, 해제는 scale 180ms·하이라이트 200ms다. 밖으로 끌기·취소된 입력의 click을 막으며, 다시 누르기와 키보드 활성화는 즉시 사용할 수 있다. modifier 키는 정상적인 조합 클릭을 취소하지 않는다. 창 포커스 이탈·숨김·unmount는 표면 상태와 이벤트 처리를 정리한다. 추가 타이머나 프레임 루프는 없다.

- 전체 단위 테스트 53개 파일 / 521개 통과. 새 입력 테스트 18개는 마우스·터치 이벤트, 빠른 재입력, 영역 밖 이동, 다른 pointer ID, pointercancel·blur·숨김·문맥 메뉴, 키보드·modifier·dispose를 확인한다. 테스트 구성 정리 후 18개를 다시 통과했다.
- 타입·lint·포맷 검사와 프로덕션 빌드 통과. 기존 lint 경고 6건은 유지한다.
- 프로덕션 브라우저의 네이티브 입력 중 표면과 아이콘의 scale 0.96, opacity 0.12, 진입 0ms를 관측했다. 해제 시 선택 상태가 바뀌면서 복원 시간은 180ms·200ms로 전환했다. 실제 Dock의 테마 버튼도 같은 결과였고 클릭 대상의 transform은 `none`이었다.
- 32px·1배의 어두운 테마에서 누르는 동안 클릭 영역은 32px, 표시 너비만 30.72px였다. 40px·1.6배의 밝은 테마와 64px·2배의 두 테마에서 기존 확대와 0.96 눌림의 합성을 확인했다. 아이콘 선명도와 고정된 표면 강조를 스크린샷으로 확인했다.
- 버튼 밖으로 끌어 놓으면 선택하지 않았다. 키보드 Enter는 선택을 즉시 바꾸고 scale 1·transition 0ms·2px 포커스 윤곽선을 유지했다. 검증 후 데모를 40px·1.6배·Files 선택으로 복원했고 테마는 원래 밝은 상태로 되돌렸다. 새 브라우저 경고·오류는 없었다.
- 동작 감소는 CSS 미디어 조건과 기존 정적 모드 연결로 처리한다. 해당 설정의 실제 브라우저 재현, 실제 터치 기기, Safari, 120Hz 성능, 연속 영상 프레임 검토는 미확인이다. 입력 중 DOM·계산 스타일 표본은 연속 영상 검증으로 간주하지 않는다.

판정: 승인한 눌림·표면 강조를 구현했다. 클릭의 실행 시점, 바깥 클릭 영역, hover 확대와 툴팁 정책을 유지하며 점프나 반복 반동은 추가하지 않았다.
